# Запуск сайта и Telegram-бота

Сайт и бот — два отдельных процесса. Сайт можно оставить на Vercel (как в текущем проекте),
а бота развернуть отдельным постоянно работающим Worker-сервисом. Бот читает тот же
локальный каталог `src/data/events.json`, что и сайт.

## 1. Важно: замените раскрытые ключи

В исходных архивах обнаружены Telegram bot token и LLM API key, записанные прямо в файлах.
Считайте их скомпрометированными: отзовите/перевыпустите токен через @BotFather и ключ у
LLM-провайдера. Не используйте старые значения. В этой сборке секреты удалены из конфигов.

## 2. Сайт

- Импортируйте репозиторий в Vercel.
- Build command: `npm run build`.
- Install command: `npm ci`.
- Если проекту требуется БД/авторизация, добавьте соответствующие переменные окружения
  из настроек вашего окружения. Для показа каталога и статики Telegram это не требуется.

## 3. Telegram-бот на Railway

1. Создайте новый проект Railway и подключите тот же репозиторий.
2. Создайте отдельный Service из репозитория.
3. В настройках сервиса задайте Dockerfile path: `Dockerfile.bot`.
4. В Variables добавьте `TELEGRAM_BOT_TOKEN` с НОВЫМ токеном от @BotFather.
5. По желанию задайте `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`. Без них бот отвечает
   по встроенному каталогу и не требует платного API.
6. Deploy. В логах должна появиться строка `bot @... polling`.

Важно: не запускайте один и тот же токен одновременно на Railway, локальном компьютере
и другом сервере. Telegram polling допускает только одного активного потребителя обновлений.

## 4. Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm ci
# задайте TELEGRAM_BOT_TOKEN в окружении
npm run bot
```

На Windows PowerShell:

```powershell
$env:TELEGRAM_BOT_TOKEN="ВАШ_НОВЫЙ_ТОКЕН"
npm run bot
```

Для сайта в отдельном терминале:

```bash
npm run dev
```

## 5. Проверка

- Откройте сайт и убедитесь, что загружается `public/logo-ufa.png`.
- Проверьте в DevTools Network, что `/fonts/Unbounded-400.ttf`,
  `/fonts/Unbounded-500.ttf`, `/fonts/Unbounded-700.ttf` и файлы Manrope отдают HTTP 200.
- Откройте Telegram-бота, отправьте `/start`, затем проверьте кнопки категорий и текстовый поиск.

Бот использует встроенный снимок каталога. Чтобы обновлять события, обновляйте
`src/data/events.json` в репозитории и повторно разворачивайте сайт и bot-worker.

## Локальный файл `.env` (Windows)

В корне проекта создайте файл с именем именно `.env` (не `.env.example`).
Можно скопировать шаблон командой `copy .env.example .env`, затем открыть `.env`
в редакторе и заполнить `TELEGRAM_BOT_TOKEN=...`. Текущая версия `telegram-bot.mjs`
сама читает `.env`; переменные окружения, заданные системой или Railway, имеют приоритет.
Не добавляйте `.env` в Git и не отправляйте его другим людям.
